# Security policy

RouteForge does not make network requests and does not execute generated route data as code. Review report files before publishing: they contain coordinates, demands, route order, and objective diagnostics from the instance you supplied.

When using custom loaders or objectives around RouteForge, treat those inputs as untrusted code and run them in an isolated environment. Report a security issue privately to the project owner; never include credentials or proprietary instances in a public issue.
